CloudClip GitHub

Comment on a video like a doc. Your agent makes the edits.

Pause, mark an area, type what should change. CloudClip turns your notes into exact timestamps and pixel boxes, and your AI agent applies them with ffmpeg.

Try the video demo Try it on an image Install
1Ask your agent

"Review ~/Videos/launch.mp4 with CloudClip." It opens the review page on your machine.

2Pause, mark, comment

Press C, drag a box or click a spot, type. Works on images too.

3Get a new file

The agent looks at each marked frame, confirms anything unclear, and writes an edited copy. Your original is never overwritten.

What your agent receives

[
  {"time": 72.4, "timestamp": "1:12.4",
   "text": "blur this logo",
   "box": {"x": 1190, "y": 86, "w": 384, "h": 108}},
  {"time": 95.2, "timestamp": "1:35.2",
   "text": "cut from here to 1:50"}
]

Seconds and source pixels, ready for ffmpeg's crop, blur, drawbox and trim.

Install

Claude Code (desktop or terminal):

/plugin marketplace add davidpn11/cloudclip
/plugin install cloudclip@cloudclip

Needs python3 and ffmpeg. With Codex, Gemini CLI, Cursor or Grok, clone the repo; the agent follows AGENTS.md, or copy skills/review into its skills folder.

Everything runs on 127.0.0.1. Your media never leaves your machine; the demo keeps comments in your browser.
